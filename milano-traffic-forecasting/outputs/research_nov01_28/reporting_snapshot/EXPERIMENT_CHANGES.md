# 본실험 실행 전 변경 기록

기준 조건: Square 1, 2013-11-01~28, 기존 `configs/experiment.json`, seed 42/43/44. 테스트 결과를 보기 전에 아래 변경을 준비했습니다.

1. `milano/preprocess.py`: 기존 전체 행 검사·국가별 합산은 유지. 파일별 MD5를 SHA256과 함께 기록하고 파일 완료 로그 추가. 공식 데이터 무결성과 진행 상황을 확인하기 위한 변경이며 집계값을 바꾸지 않음.
2. `milano/train.py`: 매 10 epoch의 validation MSE 진행 로그 추가. 모델·손실·optimizer·early stopping·seed·최적 checkpoint 선택 규칙은 변경하지 않음.
3. `scripts/validate_november.py`: 정확히 28개 날짜/파일과 공식 크기·MD5를 검증하고 기존 집계 함수를 실행. 결측·기간·간격·표본 수에 문제가 있으면 학습 이전에 중단. 통계적 큰 값은 표시만 하고 삭제/수정하지 않음.
4. `scripts/run_fixed_experiment.py`: 기존 실험 함수를 예측 horizon별 독립 프로세스에서 실행하고 결과 병합. 설정 차이는 실행 분할을 위한 horizon 목록뿐임. 모델마다 기존 CPU 단일 스레드·deterministic seed를 유지. 최대 3개 프로세스로 실행하며 30개 모델을 한 번씩 학습. 원본 설정·코드·라이브러리 버전·해시 저장.
5. 결과 요약과 시각화는 별도 모듈로 추가. seed별 실제 지표를 그대로 사용. Persistence는 결정론적이라 seed 반복 표준편차를 추정하지 않고 고정 결과로 표시. 요약 그래프에 필요한 경우 반복 변동이 없음을 0으로 표시하되 설명을 덧붙임.
6. 원본 전체 검사에서 Python float 하나씩에 NumPy `isfinite`를 호출하는 비효율을 확인. 동일한 유한값 판정을 하는 `math.isfinite`로 교체. 형식·범위·결측·집계 정책은 동일하며 학습 전 변경. 미완료 검사만 재시작하며 이미 완성된 시계열은 덮어쓰지 않도록 보호.

현재까지 학습 결과를 바꿀 논리 오류는 확인되지 않았습니다. 결과를 본 뒤 조건을 바꾸거나 유리한 모델/seed를 고르는 재실험은 하지 않습니다. 실제·예측 비교 그림의 대표 seed는 사전에 **42**로 고정하며, 모든 seed별 그림도 별도로 저장합니다.

## 학습 완료 후 저장 결과 검증 보완

CSV 재계산 검사에서 MAE 차이 약 1.43e-8로 엄격한 허용오차를 넘는 경우를 확인했습니다. 원인은 원래 float32 예측의 CSV 짧은 소수 표기를 float64로 읽어 원래 메모리 값과 다른 수로 평가한 것이었습니다. 검증 코드에서 CSV 예측을 원래 float32로 복원한 뒤 float64 정답과 계산하도록 수정했습니다. 허용오차를 완화하거나 학습·모델·예측·공식 지표를 변경하지 않았습니다. 학습은 다시 수행하지 않았습니다.
